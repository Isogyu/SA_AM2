# システムアーキテクト試験 午前Ⅱ 対策アプリ

スマホ向けの午前Ⅱ（科目A-2）対策 Web アプリです。GitHub Pages で公開しています（`docs/` 配下）。

## 収録内容

- IPA 公開の過去問 **平成21年度〜令和7年度の全16回・400問**（令和2年度は試験中止）
  - 問題文・選択肢を書き起こし，図表を含む問題は問題冊子の図を切り出して表示
  - 正解は IPA 公開の解答例に基づく
  - 全問に解説・選択肢ごとの正誤理由・覚え方（ポイント）を付与
  - 分野は試験要綱の午前Ⅱ出題分野，シラバス（SA Ver.5.2）の大項目に対応付け
- 用語集 590 語：定義，関連用語との“つながり”（関係の説明付き），その用語が出た過去問

## 機能

| 機能 | 内容 |
| --- | --- |
| おすすめ演習 | 復習期限の問題＋未回答の頻出問題＋弱点分野を自動配分 |
| 本番形式の模擬試験 | 25問・40分・4択。分野構成は `code_artifact.md` の直近5回平均。見直しフラグ・解答一覧・採点（基準点60点） |
| 間違えた問題の復習 | 間隔反復（1→3→7→16→35日）で復習期限を管理。前回間違えた問題・ブックマーク |
| 頻出問題 | 他年度とほぼ同一の“再出題”問題（68グループ・168問）を自動検出して集中演習 |
| 用語 | 検索・出題頻度順・つながりマップ・フラッシュカード。解説中の用語はタップで説明表示 |
| 出題傾向 | 分野別・年度別出題数，再出題率，シラバス対応 |
| 成績 | 分野別正答率・習得数・模試履歴・学習量。合格予測得点。バックアップの保存／復元 |

学習記録は端末のブラウザ（localStorage）に保存されます。

## 構成

```
data/answers.json        IPA 解答例から抽出した正解
data/exams/*.json        年度ごとの問題・解説・用語
data/terms/extra.json    追加の用語
code_artifact.md         分野別の出題数分析（模試の分野構成に使用）
tools/build.py           データ検証・統合 → docs/data.js，図版の切り出し
docs/                    公開する Web アプリ（index.html, app.js, style.css, data.js, img/）
```

### データ更新

```bash
python3 tools/build.py                      # data/ を検証して docs/data.js を生成
python3 tools/build.py --pdf-dir <PDF置き場>  # 図版を IPA の問題 PDF から切り出す（PyMuPDF, Pillow が必要）
```

問題の出典：独立行政法人情報処理推進機構（IPA）情報処理技術者試験 システムアーキテクト試験 午前Ⅱ 過去問題。
